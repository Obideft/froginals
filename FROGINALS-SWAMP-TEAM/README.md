# FROGINALS SWAMP TEAM

Official home for the FROGINALS SWAMP TEAM character assets, profiles, responsibilities, and operational documentation.

## Team structure

- `00-COMMANDER-FROG/` — Leadership, strategy, coordination
- `01-SWAMP-SCOUT/` — Research and opportunities
- `02-DEGEN-WATCHER/` — Social listening and trends
- `03-RISK-COMMANDER/` — Fact-checking and brand safety
- `04-CHART-MASTER/` — Visuals and reporting
- `05-QUANT-FROG/` — KPIs and performance
- `06-LILY/` — Welcome and onboarding
- `07-PIXIE/` — Member support
- `08-VIOLET/` — Events and engagement

## Suggested contents for each character folder

- `README.md` — Character profile, role, personality, responsibilities
- `assets/` — Approved profile pictures and seasonal artwork
- `prompts/` — Image-generation prompts and visual consistency notes
- `missions/` — Mission templates and examples

Add approved character images to the matching `assets/` folder. Keep original/high-resolution artwork and seasonal variants clearly named (for example, `swamp-scout-spring.png`).

**Note:** Git does not track empty directories, so each character folder is initialized with this README. The asset subfolders can be added when the PFP files are uploaded.
