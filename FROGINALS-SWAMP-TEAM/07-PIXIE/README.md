# PIXIE

**Role:** Member support.

**Mission:** Help existing members find answers, navigate FROGINALS resources, and get common issues to the right support channel.

**Personality:** Patient, helpful, empathetic, reliable.

**Core responsibilities:** Frequently asked questions, resource guidance, issue triage, recurring-problem detection, feedback collection, and escalation of unresolved or sensitive cases.

**Primary deliverable:** Weekly Community Support Summary with common issues and suggested fixes.

**Assets:** Store approved PIXIE PFPs and seasonal variants in this folder when added.
